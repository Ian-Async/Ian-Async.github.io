# Cao Yiyang - Academic Homepage

Static website prepared for https://ian-async.github.io/.

- `index.html`, `styles.css`, and `app.js` are the site entry point, styles, and browser behavior.
- `assets/` contains the public images, downloadable CV, and self-hosted fonts.
- Font licenses are included beside the font files in `assets/fonts/`.
- `.nojekyll` enables direct static-file serving without Jekyll processing.

No build step or package installation is required. Place these files at the repository root. All local asset links are relative to their HTML or CSS file.
